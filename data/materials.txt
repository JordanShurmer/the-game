# Materials table for the Noita-like game
# Format is intentionally simple so Odin can parse it with only core library.
#
# Rules:
#   - Lines starting with # are comments
#   - Blank lines are ignored
#   - A material starts with [Name]
#   - Fields are key = value
#   - Bit sets are space-separated flag names
#   - Missing fields use sensible defaults (see loader)
#
# Hot fields go in the Material struct. The simulation reads them every tick.
# Cold fields go in parallel tables. The simulation reads them rarely.
#
# Cold fields:
#   glyph       = one character for the text map
#   decays_to   = material that replaces this one when the lifetime ends
#   burns_to    = material that replaces this one when fire reaches it
#   crumbles_to = material a blast turns this into when it breaks
#
# Hot fields:
#   force       = expulsive force: the power and the reach of the blast this
#                 material makes when it goes off. 0 = it never goes off.
#                 See docs/physics.md, "Explosions".
#   luminosity  = the light this material gives, 0 to 255. See
#                 docs/lighting.md, "Every light is a material".
#
# A material with `state = Phantom` has no physical interaction. Matter
# cannot touch one and one cannot touch matter, so the cell grid never
# holds one and nothing may decay, burn, crumble or react into one. The
# world carries it as a light and a colour at a point: the orb on the
# wizard's staff is one.
#
# [Reactions] is a reserved section, read after every material so a
# row can name any material in the file. A row reads:
#   A + B -> C + D   chance
# The cell holding A becomes C and the cell holding B becomes D. The
# loader stores each row a second time with both sides and both
# results swapped, so a lookup never has to try the pair both ways.
# chance is out of 255, tested once per cell per tick. See
# docs/physics.md for the whole mechanism.

# ------------------------------------------------------------
# The lights of the world. See docs/lighting.md, "Every light is a
# material". Each one is a row here and nothing else: what it is made
# of says how bright it burns, what colour it is, and how long it lasts.
#
# The order they burn in is a rule, held by
# test_the_lights_of_the_world_are_ordered:
#   Blast 255 >= Orb_Light 255 > Light_Crystal 168 > Firefly_Light 96
# A bang is the brightest thing in the world while it lasts, and the
# trail he leaves must never outshine the orb he carries.
# ------------------------------------------------------------
